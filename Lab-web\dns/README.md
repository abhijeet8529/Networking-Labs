Company Website Hosting Using DNS and HTTP Services
Project Overview

This project demonstrates the implementation of DNS and Web Server services in Cisco Packet Tracer. A DNS server was configured to resolve a domain name to the web server's IP address, allowing users to access a company website using a friendly domain name instead of an IP address.

The project simulates a basic enterprise web hosting environment and highlights the interaction between DNS and HTTP services.

Objectives
Configure a DNS Server.
Configure a Web Server.
Create DNS records.
Host an internal company website.
Access the website using a domain name.
Verify DNS resolution and HTTP connectivity.
Technologies Used
Cisco Packet Tracer
IPv4 Addressing
DNS Service
HTTP Service

DNS Name Resolution
Internal Website Hosting

End-to-End Connectivity Testing
Verification

The project was validated by successfully resolving the domain name company.com to the web server IP address and accessing the hosted website through a web browser.

Learning Outcomes
DNS Server Configuration
HTTP Server Configuration
Domain Name Resolution
Enterprise Service Deployment
Network Troubleshooting
Conclusion

This project demonstrates how DNS and Web Server services work together to provide user-friendly access to hosted web applications within an enterprise network.
