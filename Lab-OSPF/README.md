Project 9: Enterprise Network Using OSPF
Project Overview

This project demonstrates the implementation of Open Shortest Path First (OSPF) dynamic routing in an enterprise network environment using Cisco Packet Tracer. The network consists of four interconnected routers, multiple LAN segments, switches, and end devices. OSPF Area 0 was configured to enable automatic route discovery and efficient communication between all networks.

Unlike static routing, where routes must be manually configured, OSPF dynamically exchanges routing information between routers and automatically updates routing tables whenever network changes occur. This makes OSPF highly scalable and suitable for medium and large enterprise networks.

The project focuses on enterprise network design, router configuration, OSPF implementation, route advertisement, neighbor relationships, and end-to-end connectivity verification.

Scenario

A growing organization operates multiple departments located across different office locations. Each location has its own local network and requires reliable communication with other departments. To provide scalable and efficient routing, OSPF is deployed as the dynamic routing protocol. All routers participate in OSPF Area 0, allowing them to automatically learn remote networks and maintain optimal routing paths throughout the enterprise infrastructure.

Objectives
Design a multi-router enterprise network topology.
Configure IPv4 addressing for routers and end devices.
Implement OSPF Area 0 across all routers.
Establish OSPF neighbor relationships.
Enable automatic route learning and route advertisement.
Verify routing tables and network connectivity.
Test end-to-end communication between all LANs.
