# Project 7: Multi-Branch Company Using Static Routing

## Project Overview

This project simulates a multi-branch company network using Cisco Packet Tracer. The network consists of two branch offices, Branch A and Branch B, each connected to its own local area network (LAN). Two routers are used to interconnect the branches through a point-to-point WAN link.

Static routing was implemented to enable communication between the branch networks. Each router was manually configured with routes to reach the remote network, allowing devices in different branches to exchange data successfully.

The project demonstrates fundamental networking concepts including IP addressing, subnetting, router configuration, static route implementation, routing table management, and end-to-end connectivity verification.

## Scenario

A company operates from two geographically separated branch offices. Employees in Branch A need to communicate with employees in Branch B to share files, access resources, and exchange information. Since the branches belong to different IP networks, routers are required to forward traffic between them.

To establish communication, a point-to-point connection is configured between the routers, and static routes are manually added on both routers. This enables devices from either branch to reach the remote network and communicate successfully.

## Objectives

* Design a multi-branch network topology.
* Configure IP addressing for all devices.
* Establish connectivity between routers.
* Implement static routing between branch networks.
* Verify successful communication across branches.
* Understand routing tables and packet forwarding processes.

## Technologies Used

* Cisco Packet Tracer
* IPv4 Addressing
* Static Routing
* Router Configuration
* LAN and WAN Networking
* Network Troubleshooting

## Learning Outcomes

Through this project, practical experience was gained in configuring routers, implementing static routes, managing routing tables, and troubleshooting network connectivity issues. The project also provided a deeper understanding of how routers make forwarding decisions and how communication occurs between different networks.
