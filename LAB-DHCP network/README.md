DHCP Server Configuration Using Cisco Packet Tracer
Project Overview

This project demonstrates the implementation of Dynamic Host Configuration Protocol (DHCP) in Cisco Packet Tracer. A router is configured as a DHCP server to automatically assign IP addresses and network parameters to client devices. The network consists of 10 PCs connected through a switch, eliminating the need for manual IP configuration.

The project showcases automated IP address management and simplifies network administration.

Objectives
Configure a router as a DHCP server.
Automatically assign IP addresses to client devices.
Reduce manual IP configuration.
Verify successful DHCP lease allocation.
Test network connectivity.
