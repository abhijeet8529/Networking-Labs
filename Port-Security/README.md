Project 14: Secure Switch Ports Using Port Security
Project Overview

This project demonstrates the implementation of Port Security on a Cisco switch to prevent unauthorized devices from accessing the network. Port Security was configured to allow only one device per switch port using Sticky MAC Address Learning. The switch dynamically learned and stored the MAC address of the first connected device and restricted access to any other device attempting to use the same port.

A violation policy was configured to automatically disable the port if an unauthorized device was connected, enhancing network security and protecting against unauthorized access.
